
# Student Grade Management System

## 100 Days of Coding – Day 01/100

### Project Description
A beginner JavaScript project developed as part of my 100 Days of Coding Challenge.

The project demonstrates how JavaScript fundamentals can be combined to manage student grades and generate a class report.

- Average Score Calculation
